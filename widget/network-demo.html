Integration Examples

See how different wallets would integrate StellarSafe:

📱 Lobstr Mobile

// In Lobstr app
StellarSafeWidget.init({
  partnerId: 'lobstr',
  network: 'mainnet',
  authToken: 'sk_lobstr_prod_abc123'
});

// Before transaction
StellarSafeWidget.check({
  address: recipientAddress,
  onResult: (result) => {
    if (result.riskLevel === 'DANGER') {
      showLobstrWarning(result);
    } else {
      proceedWithSend();
    }
  }
});

🔧 Freighter Extension

// In Freighter extension
StellarSafeWidget.init({
  partnerId: 'freighter',
  network: 'mainnet',
  failMode: 'closed'  // Block on high risk
});

// Check before signing
await StellarSafeWidget.check({
  address: transaction.destination
