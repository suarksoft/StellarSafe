# Extension Icons

This folder should contain the following icon files:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## How to Generate Icons

### Option 1: Online Generator
1. Go to https://icon.kitchen
2. Upload a shield icon or use the 🛡️ emoji
3. Set colors: Primary: #667eea, Background: white
4. Download all sizes

### Option 2: Manual Creation
1. Design a 512x512 icon in your favorite editor (Figma, Sketch, Photoshop)
2. Use the StellarSafe shield + star theme
3. Export as PNG at required sizes

### Option 3: Simple Emoji
1. Take a screenshot of the 🛡️ emoji
2. Resize to needed dimensions
3. Add background color

## Design Guidelines

- **Primary Color**: #667eea (purple-blue)
- **Accent Color**: #764ba2 (purple)
- **Style**: Modern, minimalist, trustworthy
- **Symbol**: Shield (protection) + Star (Stellar)

## Temporary Solution

Until proper icons are created, you can:
1. Copy any PNG files (matching sizes) as placeholders
2. The extension will still work without icons (just won't look as nice)
3. Chrome/Firefox will show a default puzzle piece icon
